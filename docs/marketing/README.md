# 课刻宣传素材规范

本目录记录课刻对外展示时的统一信息、视觉边界和素材规格，避免每次发布重新设计，也避免宣传素材脱离产品本身。

## 视觉原则

课刻的对外视觉必须同时继承两个已经存在的系统：

- **课刻官网**：`#f5f5f7`、`#1d1d1f`、系统字体、细线框、真实产品界面和极少量 `#0071e3`；
- **Tyr1onX 个人页**：`#0d0d10`、`#f4f4f7`、轨道与时间关系、克制留白、项目自身图标。

宣传素材必须遵守：

1. 只使用仓库中的真实课刻图标、真实界面截图或从真实页面直接录制的画面；
2. 不生成或伪造软件界面，不用 AI 生成的设备模型、桌面场景、书本、植物、玻璃卡片或装饰物；
3. 不使用蓝紫渐变、米白商业海报、霓虹光晕、抽象流体和无意义背景图形；
4. 装饰只允许服务“时间流动”概念，例如细轨道、节点、时间线和结构网格；
5. 蓝色只使用官网现有的 `#0071e3`，且只作为状态和交互强调色；
6. 任何宣传图都必须先让人认出课刻，而不是先认出一种流行设计模板。

## 核心定位

主标题：

> 让一天在桌面上缓慢流动。

产品说明：

> 从学校教务系统导入课表，在 Windows 桌面查看当前课程、下一节与完整周课表。无需账号，数据只保存在本机。

面向搜索和传播时可以使用：

> 把学校教务系统里的课表，放回 Windows 桌面。

技术说明只作为补充：

> A local-first Windows timetable and course schedule desktop widget built with Tauri, Rust and TypeScript.

当前封面采用：

- 个人页深色宇宙背景；
- 课刻官网的系统字体和 `#0071e3`；
- 真实课刻图标；
- 轨道、时间线和产品信息；
- 无伪造软件截图、无场景装饰、无渐变。

## 15 秒演示脚本

1. **0–3 秒：今天的课程**
   - 直接录制真实桌面组件初始状态。
   - 画面中同时出现日期、教学周和今天课程数量。
2. **3–8 秒：正在上课**
   - 使用内置演示模式推进时间。
   - 当前课程成为视觉中心，进度和剩余时间自然变化。
3. **8–11 秒：课程交接**
   - 当前课程结束，下一节课程上移。
   - 保留程序真实动画，不用剪辑伪造状态变化。
4. **11–13 秒：完整周课表**
   - 打开真实“课表与设置”窗口，展示完整周课表。
5. **13–15 秒：下载引导**
   - 文案：`免费下载 · Windows 10 / 11 · 数据仅存本机`
   - 结尾使用真实课刻图标和仓库地址。

## 隐私检查

发布任何截图、GIF、视频或样例文件前，必须确认：

- 不包含真实姓名和学号；
- 不包含不应公开的教师、班级或联系方式；
- 教室和课程信息已经替换为演示数据；
- 浏览器、文件路径、通知和系统托盘中没有其他私人信息；
- 样例只保留复现兼容性问题所需的最小内容。
