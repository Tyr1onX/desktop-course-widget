# 下载与首次使用

课刻目前面向 Windows。稳定版 **v0.4.0** 支持从学校教务系统导出的 `.xlsx` 建立课表；预发布版 **v0.5.0-beta.5** 在此基础上提供本地 PNG/JPG 课表截图识别（Beta），并让识别结果先进入人工复核再创建课表。

## 下载

- [下载最新稳定版 v0.4.0](https://github.com/Tyr1onX/desktop-course-widget/releases/latest)：适合日常使用。
- [体验 Beta v0.5.0-beta.5](https://github.com/Tyr1onX/desktop-course-widget/releases/tag/v0.5.0-beta.5)：包含截图识别（Beta）和当前预发布修复。

GitHub 的 `releases/latest` 默认只返回最新稳定版，不会把 prerelease 当作 latest。无论选择哪个版本，都在对应 Release 的 **Assets** 中下载名称以 `x64-setup.exe` 结尾的 Windows 安装程序。

::: warning Windows 安全提示
当前安装包尚未进行商业代码签名。Windows 可能显示“Windows 已保护你的电脑”或“未知发布者”。请先确认安装包来自本项目官方 GitHub Release，再点击“更多信息”与“仍要运行”。
:::

## 从 Excel 导入

1. 在学校教务系统中导出 `.xlsx` 格式的课表。
2. 启动课刻，打开“课表与设置”。
3. 点击左上角的当前课表选择器，选择“导入新课表”。
4. 选择 Excel 文件，并确认第一教学周星期一的日期。
5. 检查导入复核结果，按需补充缺失地点或调整课程信息。
6. 确认后创建并应用课表。

导入完成后，桌面组件会根据当前日期、教学周和作息时间显示今天的课程。

## 从课表截图导入（Beta）

截图识别仅在 **v0.5.0-beta.5** 预发布版中提供，识别过程和课表数据都留在本机。

1. 打开“课表与设置”，从当前课表选择器进入“导入新课表”。
2. 选择 **PNG / JPG 课表截图**。请使用完整单张截图，尽量包含星期标题、节次和全部课程；暂不支持多图拼接。
3. 等待本地识别完成后，进入“检查截图识别结果”。
4. 逐项核对课程名称、星期、节次、周次、地点等信息，并手动修正不准确的字段。
5. 确认复核结果后创建新课表。已有课表不会被直接覆盖。

截图布局差异较大时，Beta 识别结果可能需要更多人工修正；如果学校可以稳定导出 `.xlsx`，Excel 仍是更成熟的导入方式。

## 系统托盘

关闭桌面组件只会把它隐藏到系统托盘，并不会退出程序。右键托盘中的课刻图标，可以：

- 显示或隐藏桌面组件；
- 打开完整课表与设置；
- 设置是否开机启动；
- 完全退出程序。

## 从旧版本升级

安装新版本时，安装程序可能处理历史“桌面课表”或旧版课刻安装。请保留应用数据，以便原有课表和设置继续使用。v0.5.0-beta.5 还补强了历史品牌与双安装目录的迁移验证。
