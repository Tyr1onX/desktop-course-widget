# 下载与首次使用

桌面课表目前面向 Windows，安装后可以从学校教务系统导入 `.xlsx` 课表，并在桌面显示当天课程。

## 下载

1. 打开 [GitHub Releases](https://github.com/Tyr1onX/desktop-course-widget/releases/latest)。
2. 在最新版本页面下方展开 **Assets**。
3. 下载名称以 `x64-setup.exe` 结尾的 Windows 安装程序。
4. 双击安装程序并按照界面完成安装。

::: warning Windows 安全提示
当前安装包尚未进行商业代码签名。Windows 可能显示“Windows 已保护你的电脑”或“未知发布者”。请先确认安装包来自本项目官方 GitHub Release，再点击“更多信息”与“仍要运行”。
:::

## 第一次导入课表

1. 在学校教务系统中导出 `.xlsx` 格式的课表。
2. 启动桌面课表，打开“课表与设置”。
3. 点击左上角的当前课表选择器。
4. 选择“导入新课表”。
5. 选择 Excel 文件，并确认第一教学周星期一的日期。
6. 检查导入预览，按需补充缺失地点或调整课程信息。
7. 确认后应用课表。

导入完成后，桌面组件会根据当前日期、教学周和作息时间显示今天的课程。

## 系统托盘

关闭桌面组件只会把它隐藏到系统托盘，并不会退出程序。右键托盘中的课表图标，可以：

- 显示或隐藏桌面组件；
- 打开完整课表与设置；
- 设置是否开机启动；
- 完全退出程序。

## 从旧版本升级

安装新版本时，安装程序可能先打开旧版本卸载界面。请勿勾选 **Delete the application data**，这样原有课表和设置可以继续保留。

下一步可以查看[课表与课程管理](./schedule-management)。
