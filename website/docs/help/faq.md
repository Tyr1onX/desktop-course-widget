# 常见问题

## 为什么 Windows 提示未知发布者？

当前安装包还没有商业代码签名，因此 Windows SmartScreen 可能提示来源未知。请只从本项目的官方 GitHub Release 下载，并在运行前核对发布页面中的文件名和校验信息。

## 为什么关闭窗口后程序还在运行？

关闭桌面组件只会将它隐藏到系统托盘。这可以让课表继续在后台运行，并保留托盘入口。需要完全退出时，请右键系统托盘中的课表图标并选择退出。

## 课表数据会上传吗？

不会。Excel 文件和 Beta 版的 PNG/JPG 课表截图都在本机处理，课表与设置保存在应用专属数据目录中，不需要登录，也不会主动上传到服务器。

Windows 数据目录通常为：

```text
%LOCALAPPDATA%\com.coursewidget.desktop\
```

公开反馈截图、日志或样例文件前，请遮住姓名、学号、教师、教室和其他个人信息。

## 稳定版和 Beta 有什么区别？

当前稳定版是 **v0.4.0**，GitHub 的 `releases/latest` 会指向它。**v0.5.0-beta.5** 是 prerelease，包含本地课表截图识别（Beta）与当前预发布修复，需要从对应的 Beta Release 单独下载。

截图识别不是稳定版 v0.4.0 的功能；如果主要依赖 Excel 导入并更看重稳定性，优先使用稳定版。

## 截图识别为什么需要人工复核？

不同学校的课表图片在网格、字体、合并单元格和课程排布上差异很大。Beta 版会先在本机识别，再把结果交给你逐项检查和修正，确认后才创建课表。建议使用包含完整星期栏、节次和课程区域的清晰单张 PNG/JPG 截图。

## 为什么 Excel 导入失败？

不同学校和教务系统导出的 Excel 结构可能不同。可以先确认：

1. 文件扩展名是 `.xlsx`；
2. 文件可以在 Excel 或 WPS 中正常打开；
3. 课表中包含星期、节次、课程名称等基本信息；
4. 没有把网页截图或 PDF 改名为 `.xlsx`。

仍然无法导入时，请在 [GitHub Issues](https://github.com/Tyr1onX/desktop-course-widget/issues) 中说明学校课表的大致结构、应用版本和报错信息。不要直接公开包含个人信息的原始课表。

## 目前支持哪些系统？

目前只正式支持 Windows。macOS、Linux、移动端和网页端暂未提供安装版本。

## 支持课程提醒或云同步吗？

当前版本暂不支持课程通知、自动更新和云同步。现阶段优先完善课表导入、编辑、桌面显示和稳定性。

## 升级会丢失课表吗？

正常升级会保留应用数据。安装程序出现旧版卸载界面时，请勿勾选 **Delete the application data**。
